This device isn’t paired

Approvals only work from devices you’ve paired. Bouncer prints a single-use pairing link when it starts.

  1. On the Mac, run npm start in ~/dev/bouncer.
  2. Open the iPhone link it prints, with Tailscale on.
  3. This page reloads as a paired device. Links expire after 10 minutes and work once.

Already paired and seeing this? Bouncer restarted. Sessions live in memory, so pair again.

Who can do what

  1. The agent proposesClaude Code reaches Fo only through Bouncer’s hook. It can’t approve or release its own request.
  2. Policy sortsRead-only calls and email to yourself go through. Money and strangers are denied. Everything else waits for you. If Bouncer is down, the call is blocked.
  3. You authorizeOnly a paired device can approve. An approval covers the exact message, by SHA-256 hash, and releases it once.
  4. Evidence stays separate“Fo says” is Fo’s own report. “Independently confirmed” means someone checked outside Fo, such as the recipient’s inbox.
